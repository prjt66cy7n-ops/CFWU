# Draft artwork

care-and-tack-sheet.png is an initial generated 4×4 transparent prop sheet for visual review, not integrated runtime assets. Uploaded concept retrieval failed at the image service; this draft used a written description of the approved art direction instead of direct image references.

Rows, left to right:
1. Brush, hoof pick, sponge, hose.
2. Empty bucket, filled bucket, broom, wheelbarrow.
3. Carrots, apple, hay bale, egg basket.
4. Saddle, pink saddle pad, bridle, rosette.

The sheet needs separation and edge cleanup before use. Several silhouettes approach or cross nominal cell boundaries, so automatic equal-grid slicing is unsuitable. Saddle and pad also need matched horse-facing views for equipped overlays. Additional outfit palettes, animated horses/riders/unicorns, scenery layers, task states, and UI assets are outstanding. Do not present this sheet as a completed asset library.
